# AI110 Instructor Demos

Starter code and instructor prompts used during AI110 class demonstrations.

## Repository layout

Each instructor demo has its own top-level folder named for the module and
week. For example:

```text
Module 2 Week 3/
  starter_code.py
  instructor_prompts.md
```

- `starter_code.py` contains the exact Python starter code used at the
  beginning of that demo.
- `instructor_prompts.md` records the prompts used during that specific demo.

## For students

Use these materials to review the demo after class. They are examples of a
development workflow, not the only correct way to complete an activity.
